Page boundary rules (page-local parsing):
- Parse exactly what is printed on the CURRENT page. Every line of the current-page transcription becomes MDF, and no text from any other page does.
- Each page's MDF is appended directly after the previous page's MDF to form the dictionary, so an entry that crosses a page break is split between the two pages' outputs.
- Entry that starts on this page and runs past the bottom: emit only the part printed on this page. Stop where the page stops, even mid-entry or mid-sentence, and keep a trailing hyphen exactly as printed. Do not complete the entry from memory or guesswork; the next page's output continues it.
- Lines at the top of this page that continue an entry begun on the previous page: emit them first, tagged with the markers they carry inside that entry (\sn, \ge, \xv, \xe, \se, …). Do NOT emit a \lx line for them, and do not repeat or invent the parent headword.
  • Example: \lx ala starts on page_53 and its sub-forms like —alas nuwebi print at the top of page_54. page_53 emits \lx ala with only the fields printed on page_53. page_54 begins with the \se alas nuwebi block (no \lx above it), then continues with the entries whose headwords start on page_54.
- Field broken by the page break (a gloss, definition or example sentence that the previous page left unfinished): begin this page by re-opening that same marker with the remaining words. Do not choose a different marker for the fragment.
- <previous_page> holds the end of the previous page's transcription. Use it ONLY to work out which entry, sense and field the top-of-page lines continue, so they get the right markers. Never copy text from <previous_page> into the output.
- The only page image is the CURRENT page. No next-page context is provided or needed.
