Step 5 of 6

Configure the agentic loop

Agentic loop

After each page is produced, an Evaluator model checks the output against its source and proposes specific edits. An Editor model verifies each edit against the same source and applies the ones it confirms, then the Evaluator checks again. This repeats until the page is accepted, the iteration limit is reached, or the loop stops making progress.

The loop catches more mistakes, but it adds model calls, so a run takes longer and costs more.

Custom loop settings

Choose which stages the loop checks, how long it may run, and which model plays each role.
